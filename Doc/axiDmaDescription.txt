Data Flow and Operations

Register Access (CPU Interface): The CPU can access control and status registers within the axiDMA entity to:

Configure DMA channels (start address, length, etc.).
Start/stop DMA operations.
Check DMA status.
Channel 0 (CPU/AXI): This channel provides direct memory access from the CPU to the external AXI memory, supporting both cached and uncached operation. The cache is write-back.

The FSM checks if the requested address is in the cache.
If there is a cache hit and it is a read operation, the data comes from cache.
If there is a cache miss, the controller tries to read a cache line from the ddr memory, and stores it in the cache. The data from the cache line is then returned to the CPU.
If it is a write, the write can happen to both the cache and the ddr memory. In case the cache does not contain requested data, it will be written to the ddr memory only.
Channel 1 (Graphics Display): This channel fetches data from AXI memory and stores it in a line buffer (dmaCh1BufRam).

ch1DmaRequest triggers the transfer.
The data is read from the AXI master bus and written to the dmaCh1BufRam.
The graphics display can then read the data from ch1BufDOut.
Channel 2 (Block Transfers): This channel handles large block transfers between memory locations. It has several modes, controlled by the ch2Command register.

Fill (00): Fills a block of memory with a specific value (ch2Input0).
Read (01): Reads a block of memory from the source address (ch2SaAddress) and stores it in the internal buffer.
Write (02): Writes the contents of the internal buffer to the destination address (ch2DaAddress).
Read and Shift (03): Reads a block, shifts the data right in the buffer, and then writes it.
Masked Write (04): Writes the data to the block ram, but only in locations where the color is not equal to a predefined color.
The ch2TransferLength, ch2TransferCounter, ch2BufPointer, ch2SaPointer, ch2DaPointer registers control the transfer.
Channel 3 (Blitter): Similar to channel 0, this channel provides direct memory access to the AXI RAM, potentially used for more specialized graphics operations. It also supports cached and uncached operations.

Cache: This is a 4-way set associative cache, each way can contain 64 data elements of 128 bits.

The tag ram contains the higher bits of the memory address, to determine whether the data is in cache or not.
The data ram contains the cache data, divided into 4 ways.
The cache can be flushed by the triggerCacheFlush signal.
The cache uses write-back policy.
